## _Lensed AgN search in lssT using machinE leaRNing_

Gravitationally lensed quasars are predicted to appear, and be efficiently detected, as extended features in wide field optical imaging survey "difference images" (e.g. [Kochanek et al 2006](https://ui.adsabs.harvard.edu/abs/2006ApJ...637L..73K/abstract), [Dux et al 2024](https://ui.adsabs.harvard.edu/abs/2024A%26A...682A..47D/abstract)). We are developing just such a search in the Rubin Observatory LSST data, which will include automatically generated Alerts for all difference image analysis sources.    

This python package is work in progress: ultimately the `lantern` repo will include code to carry out the following tasks:
* Characterize (and visualize) the properties of Rubin `diaSources`, either from the Rubin Alert Stream or from injection/reprocessing experiments using the LSST Science Pipelines.
* Filter the Rubin Alert Stream for `diaSources` that are consistent with having been generated by a strongly gravitationally lensed (i.e. multiply-imaged) quasar. This is the _First Cut_ in our search for LSST lensed AGN. We are anticipating using the [ANTARES](https://antares.noirlab.edu/) alert broker for executing the filtering. 
* Cluster (in space and time) `diaSources` (especially those tagged in the First Cut) and classify those clusters as having been generated by a strongly gravitationally lensed (i.e. multiply-imaged) quasar. This is the _Second Pass_ in our search for LSST lensed AGN.
* Visualize lensed AGN candidates and their measured properties, including with the Alert postage stamp images.

## Running the Notebooks

The training notebooks are designed to be updated by the user depending on their needs, and the stage of training, filtering, and classification. Broadly, they are related as follows. 
- The `lantern_training_data_processing.ipynb` notebook prepares the training data for both the _First Cut_ and _Second Pass_. Note that these might be slightly different training sets, as detailed in the relevant notebooks and in the training version descriptions below. These settings can be modified in `lantern_training_data_processing.ipynb` accordingly. Currently, the notebook is set up to save the training data 2.0.8, for training a first implementation of _Second Pass_ classifier.
- `lantern_first_cut_filter.ipynb` is the notebook that trains the _First Cut_ filter, and saves the trained model. This requires training data generated by `lantern_training_data_processing.ipynb`.
- `lantern_second_pass_classifier.ipynb` is the notebook that trains the _Second Pass_ classifier, and saves the trained model. This requires training data generated by `lantern_training_data_processing.ipynb`, as well as a trained _First Cut_ filter generated by `lantern_first_cut_filter.ipynb`. Note that the relevant names of the training data and filter can be altered as needed. 

## _First Cut_ Implementation at ANTARES
We are currently running a version of our _First Cut_ filter at ANTARES. The filter tags loci as LAGN targets with our tag, `lantern_xgboost_t2.0.7_c0.95`. `t2.0.7` refers to the model training version (detailed below). `c0.95` indicates that we have set the model threshold to 95% completeness, based on our survey-scale projections. 

The code for this filter can be found on the [ANTARES DevKit GitLab](https://gitlab.com/nsf-noirlab/csdc/antares/devkit/-/tree/main/antares_devkit/filters/lantern). Tagged LSST loci can be found [here](https://antares.noirlab.edu/loci?query=%7B%22currentPage%22%3A1,%22filters%22%3A%5B%7B%22type%22%3A%22terms%22,%22field%22%3A%22tags%22,%22value%22%3A%5B%22lantern_xgboost_t2.0.7_c0.95%22%5D,%22options%22%3A%7B%7D,%22text%22%3A%22Tags%3A%20lantern_xgboost_t2.0.7_c0.95%22%7D,%7B%22type%22%3A%22exists%22,%22field%22%3A%22properties.survey.lsst%22,%22text%22%3A%22Survey%3A%20LSST%22%7D%5D,%22sortBy%22%3A%22properties.newest_alert_observation_time%22,%22sortDesc%22%3Atrue,%22perPage%22%3A25%7D). In addition, versions of our trained _First Cut_ model can be found in our [Google Drive folder](https://drive.google.com/drive/folders/1CyMhprlKdYU4XlAR9N9sf2L_QLvOeoAf). More detail about these training sets can be found in the notebooks provided, but broadly, we use DP1 sources as our non-LAGN dataset, and injections of simulated lenses into DP1 as our true LAGN dataset.

| Training Version | Description |
|---|---|
| t2.0.8 | Same as t2.0.7, except we use ECDFS, Galactic, and Ecliptic DP1 data, and also include all DP1 cols for _Second Pass_ training|
| t2.0.7 | Same underlying data as t2.0.6, except we use an earlier version of `xgboost==2.1.4` (instead of `3.2.0`) for compatibility with ANTARES|
| t2.0.6 | Updated moment equation in `data_processing.py` to measure PSF moment in pixels|
| t2.0.5 | Uses all v2.0 injections (3000+ simulations), and assign unique `lens_id` to non-LAGN based on 3as radius clustering|
| t2.0.4 | Uses all v2.0 injections (3000+ simulations), and splits non-LAGN into three sky regions for test, train, and eval sets (previous versions did NOT cluster non-lenses). Non-LAGN are from ECDFS field only.|
